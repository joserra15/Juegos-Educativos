      🌈 Mundos Mágicos

      👪 Ayuda para familias

      Mundos Mágicos es un juego educativo para practicar contenidos de Infantil (5 años) y de 3º y 4º de Primaria: contar, sumar, leer, matemáticas, lengua, ciencias, sociales, inglés, lógica y visoespacial, a través de mundos temáticos, retos y recompensas.

      🎮 ¿Cómo se juega?

      • Elige un mundo según el curso y el área.
      • Cada mundo tiene varias fases con retos de ese contenido.
      • Al resolverlos se liberan recompensas y se abre la siguiente fase.
      • Las fases se pueden repetir para mejorar el tiempo y los puntos.

      🏆 Ranking y superación

      El juego incluye un ranking para comparar avances de forma sana. El objetivo principal es mejorar las propias marcas.

      🔐 Nombre y PIN secreto

      • Cada jugador elige un apodo.
      • El juego genera un PIN secreto visible en la 🎒 Mochila.
      • Si se juega desde otro dispositivo o navegador, será necesario introducir el mismo nombre y PIN.

      📱 Dispositivos

      Se puede jugar desde móvil, tablet u ordenador usando la misma dirección web. El progreso se sincroniza automáticamente cuando hay conexión.

      🛡️ Privacidad

      No se guardan datos personales. Solo se almacena el apodo y el avance en el juego. No se usan correos electrónicos ni contraseñas.

      ♻️ Aprender es repetir

      Repetir las fases forma parte del aprendizaje. El objetivo es mejorar poco a poco y disfrutar del proceso.

      Finalidad del sitio web
      Esta aplicación web tiene finalidad educativa. Ofrece juegos interactivos para practicar y reforzar contenidos de Infantil y de 3º y 4º de Primaria (España), alineados con la LOMLOE, en un entorno lúdico y motivador. Incluye mundos de Infantil (contar, sumar y leer), Matemáticas, Lengua, Ciencias Naturales, Ciencias Sociales, Inglés, Lógica y Visoespacial, con retos, fases, progreso individual y actividad colaborativa de clase.

      Uso del sitio
      El uso de esta aplicación implica la aceptación del presente aviso legal. El contenido está dirigido a un uso educativo, tanto en el ámbito familiar como escolar. Está pensada para alumnado de Educación Primaria y para el acompañamiento de familias y docentes.

      Datos personales y privacidad
      Esta aplicación no solicita ni almacena datos personales identificativos (nombre real, domicilio, documento de identidad, correo electrónico ni contraseñas). Únicamente se guarda un apodo elegido por el jugador, un PIN secreto generado por la aplicación para recuperar la partida en otro dispositivo, y el progreso del juego (puntos, tiempos, fases liberadas y recompensas). El progreso puede sincronizarse en la nube cuando hay conexión, asociado al apodo y al PIN.

      Uso de cookies y almacenamiento
      Esta aplicación no utiliza cookies de seguimiento ni cookies publicitarias. Emplea almacenamiento local del navegador (y, si procede, sincronización remota del progreso) exclusivamente para el funcionamiento del juego.
